How to read these labels
  • Difficulty is an estimate from test-patch size, files touched and prompt length. It is not measured model performance.
  • Issue type (bug or feature) is predicted by a classifier trained mostly on AI-made labels. "Confident" means probability of at least 0.70. Predictions are less reliable for Chinese-language prompts.
  • Clusters group tasks with similar text. The names are short descriptions, not official categories.
  • Language is the programming language of the test files.
